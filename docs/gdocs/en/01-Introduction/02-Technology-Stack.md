# Technology Stack

AfiLite is developed using modern, lightweight, and scalable technologies. These choices aim to both simplify project maintenance and provide a flexible working environment for developers.

## Backend

- **Node.js:** Provides a high-performance and scalable server environment thanks to its asynchronous and event-driven architecture.
- **Express.js:** A minimalist and flexible web application framework for Node.js. It allows us to build our APIs quickly and efficiently.
- **Knex.js:** A SQL query builder. It enables us to work easily with different databases (SQLite, PostgreSQL, MySQL, etc.) and increases security against vulnerabilities like SQL injection.
- **SQLite:** A serverless, zero-configuration, self-contained database engine. It is ideal for the development environment and can also be used for production in small to medium-sized projects.
- **jsonwebtoken (JWT):** Provides a secure and standard method for managing user sessions.
- **bcrypt.js:** Used for securely hashing passwords.

## Frontend

- **Next.js:** A production-ready React framework that supports modern React features like Server-Side Rendering (SSR) and Static Site Generation (SSG).
- **React:** A popular JavaScript library for building user interfaces.
- **Tailwind CSS:** A utility-first CSS framework that enables the rapid creation of modern interfaces. The `prose` plugin makes it easy to style text-based content (like contracts).

## Other Tools and Libraries

- **Nodemon:** Automatically restarts the server by monitoring file changes during development.
- **ESLint:** A linter tool used to improve code quality and ensure style consistency.
- **Jest & Supertest:** Used for unit and integration testing of the backend APIs.
- **Moment.js:** (Used temporarily) Was used to parse, validate, and format date and time data.

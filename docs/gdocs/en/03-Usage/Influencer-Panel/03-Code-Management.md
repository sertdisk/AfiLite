# Influencer Panel: Code Management

This section explains how to create, manage, and track the status of your discount codes on the AfiLite platform. Codes are the foundation of your earnings.

## 1. Creating a Code

You can create a new discount code either on the influencer dashboard or directly on the code management page. The code creation process is simple:

1.  **Code Field:** Choose a unique code between 5 and 10 characters long, consisting of letters and numbers. Letters will automatically be converted to uppercase.
2.  **Create Button:** Click the "Create Code" button after entering your code.

**Important Notes:**

*   Every code you create requires admin approval. Your code will become active and usable only after it has been approved.
*   The approval process typically takes a few days. During this period, your code's status will appear as "Pending Approval."
*   Once your code is active, the discount and commission rates determined by the system will be automatically applied. You can view these rates in the code details.

## 2. Viewing Existing Codes

On the code management page, you can list all the discount codes you have created and their current statuses.

### Code Details

The following information is provided for each code:

*   **CODE:** Your influencer code.
*   **Creation Date:** The date the code was added to the system.
*   **Approval Date:** The date the code was approved by the admin and became active (only for active codes).
*   **Status:** Indicates whether the code is active or pending approval (e.g., Active, Pending Approval).
*   **Discount Rate:** The percentage discount customers will receive using this code (e.g., 10%).
*   **Commission Rate:** The percentage commission you will earn through this code (e.g., 20%).

### Code Statuses

*   **Active:** Your code is usable, and your customers can get a discount using this code, while you earn a commission.
*   **Pending Approval:** Your code is currently under review by the admin and awaiting approval. The code cannot be used during this process.

## 3. Tips for Using Your Codes

*   **Social Media Shares:** Share your code in your social media posts, stories, or bio.
*   **Content Integration:** Naturally integrate your code into your content, such as product reviews, blog posts, or videos.
*   **Special Campaigns:** Encourage code usage by running special campaigns or announcements for your followers.

Code management is a critical tool for maximizing your earnings on the AfiLite platform. It is recommended that you regularly check the status of your codes and effectively promote your active codes.

# Influencer Panel: Dashboard

Upon logging into the influencer dashboard, you will find a summary of your overall performance and key information. This page allows you to track the status of your codes, your balance, recent sales, and payment history all in one place.

## 1. Overview

The top section of the dashboard provides general information about your account status and when you joined the system:

*   **Account Status:** Indicates whether your application has been approved or suspended.
*   **Join Date:** The date you registered with the system.
*   **Days Since Application:** The number of days passed since you joined the system.

## 2. Code Management

This section allows you to create discount codes and view the status of your existing codes.

### Create New Code

If you don't have a code yet or wish to create a new one, you can use the form in this area:

*   **Code (5-10 characters):** Enter your desired code. It can contain letters and numbers. Letters will automatically be converted to uppercase.
*   **Create Code Button:** Click to create the code.

**Important Note:** Your created code will become active after admin approval. Once the approval process is complete, you can view the discount and commission rates for your code.

### Existing Codes

All your created codes are listed in this section with their status and rates:

*   **CODE:** Your discount code.
*   **Creation Date:** The date the code was added to the system.
*   **Approval Date:** The date the code was approved by the admin and became active (only for active codes).
*   **Status:** Shows whether the code is active or pending approval (Active / Pending Approval).
*   **Discount Rate:** The percentage discount customers will receive using this code (only for active codes).
*   **Commission Rate:** The percentage commission you will earn through this code (only for active codes).

## 3. Performance Area

This section allows you to track your earnings and sales performance.

*   **Current Balance:** Your current balance amount.
*   **Recent Sales:** A list of your most recent sales made through your codes. Each sale shows the date, customer URL, product, amount, and your earned commission.
*   **Pagination:** If you have many sales, your sales history will be displayed in pages, and you can navigate between them.
*   **Latest Payment Information:** Contains details such as the date, amount, balance before and after the latest payment made to you.
*   **Payment History Link:** Redirects to the [Payment History](./05-Payment-History.md) page to view your complete payment history.

### Overall Performance Chart

There is a chart showing your sales count and commission trend over the last 30 days. This chart helps you visually assess your performance.

All information on the dashboard provides you with a comprehensive overview to effectively manage your affiliate marketing activities.

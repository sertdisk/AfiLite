# Admin Panel: System Settings

The "Settings" section in the admin panel allows you to manage critical configurations that affect the overall operation of the AfiLite platform. This section is used to set commission rates and manage contract versions.

## 1. Commission/Discount Rate Adjustment

This section allows you to set default commission and discount rates that will apply to all influencer codes. These rates will be valid for newly created codes and existing codes.

*   **Discount Percentage (%):** Determines the discount rate customers will receive using influencer codes (a value between 1-100).
*   **Commission Percentage (%):** Determines the commission rate influencers will earn from sales made through their codes (a value between 1-100).

You can save these settings by clicking the "Update Rates" button. These changes will affect all active codes in the system, and updated rates will apply to new sales. Commissions from previous sales are not affected by this change.

## 2. Contract Management

This section allows you to create and manage versions of contracts made with influencers. AfiLite supports contract versioning, so you can archive past contracts and always have a current active contract.

### Creating a New Contract Version

*   **New Contract Content:** Enter the full text of the contract in this area. It can be in Markdown or plain text format.
*   You can create a new contract version by clicking the "Create New Contract" button.

**Important Notes:**

*   When you create a new contract, the existing active contract in the system is automatically deactivated, and your newly created contract becomes active.
*   The most current active contract is always displayed in all influencer applications and relevant areas.

### Existing Contract Versions

In this section, you can view all contract versions registered in the system as a list:

*   **Version:** The version number of the contract (e.g., v1, v2).
*   **Status:** Indicates whether the contract is active (Active / Inactive).
*   **Creation Date:** The date the contract was added to the system.
*   **Action:** You can use the "View" button to see the full content of the contract.

The System Settings section gives you full authority to control the fundamental rules and operation of the AfiLite platform. Managing these settings carefully ensures the stable and fair operation of your platform.

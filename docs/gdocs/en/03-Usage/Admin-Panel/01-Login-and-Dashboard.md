# Admin Panel: Login and Dashboard

The AfiLite Admin Panel provides a central interface for you to manage and oversee the entire system. This section explains how to log in to the admin panel and what information you can access through the main control panel (Dashboard).

## 1. Admin Panel Login

Access to the admin panel is provided through a dedicated login page and is restricted to authorized admin users only.

*   **Access:** Navigate to `http://localhost:4000/admin/login` in your browser to view the admin login page.

### Login Credentials

*   **Email:** The email address of your admin account.
*   **Password:** The password of your admin account.

Upon successful login, you will be redirected to the Admin Dashboard page.

**Default Admin Credentials:**

*   **Email:** `admin@afi.com`
*   **Password:** `123456`

## 2. Admin Dashboard

The Admin Dashboard offers a quick overview of the system's overall status. Here, you can see important metrics and summary information on a single screen.

### Overview Metrics

The Dashboard includes the following main metrics:

*   **Total Influencers:** The total number of influencers registered in the system.
*   **Active Influencers:** The number of influencers whose applications have been approved and are active.
*   **Pending Influencer Applications:** The number of influencer applications awaiting approval.
*   **Total Discount Codes:** The total number of discount codes created in the system.
*   **Active Discount Codes:** The number of discount codes currently active and usable.
*   **Total Sales:** The total number of sales that have occurred over all time.
*   **Total Sales Amount:** The total revenue generated from all sales.
*   **Total Paid Commission:** The total amount of commission paid to influencers to date.
*   **Total Unpaid Commission:** The total amount of earned commissions that have not yet been paid to influencers.

### Recent Activities and Alerts

The Dashboard may also display recent important events or alerts in the system. For example, a new influencer application or a critical system alert.

The Admin Dashboard is a powerful tool for monitoring the health and performance of the system in real-time. For more detailed management operations, you can use the relevant sections in the left menu.

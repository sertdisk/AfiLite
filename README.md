# AfiLite

**A minimal, headless-first affiliate marketing platform for digital products.**

AfiLite is a lightweight web service built with Node.js, Express, and SQLite that allows you to manage sales and commission payouts for your influencer/affiliate partners. It's designed to be simple, flexible, and easy to integrate.

---

**Dijital ürünler için minimal, başsız-öncelikli bir satış ortaklığı platformu.**

AfiLite, influencer/affiliate ortaklarınız aracılığıyla yapılan satışları ve komisyon ödemelerini yönetmenizi sağlayan, Node.js, Express ve SQLite ile oluşturulmuş hafif bir web servisidir. Basit, esnek ve kolay entegre edilebilir olacak şekilde tasarlanmıştır.

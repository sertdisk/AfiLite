# AfiLite

## 🇬🇧 AfiLite: Your Gateway to Seamless Affiliate Marketing

AfiLite is a minimal, headless-first web service designed to manage sales and commission payouts for digital products through influencer/affiliate partners. Built with Node.js, Express, and SQLite, it offers flexible deployment options, running headful or headless on Windows, Linux, or a single machine.

🌟 **AfiLite (actively under development)**
Responsibility for use is entirely yours.

🚀 **Next-Generation Solution for Digital Sales**

AfiLite is a discount code-based affiliate marketing platform that empowers brands to boost sales while enabling influencers to earn income effortlessly. It's a straightforward process:

-   Customers get discounts using a code.
-   Influencers earn commissions through the same code.
-   Brands increase sales and visibility.

This triple win-win model ensures a reliable and transparent operation.

## 🇹🇷 AfiLite: Sorunsuz Satış Ortaklığına Açılan Kapınız

AfiLite, dijital ürünlerin influencer/affiliate ortakları aracılığıyla satışını ve komisyon ödemelerini yöneten minimal, başsız-öncelikli bir web servisidir. Node.js, Express ve SQLite ile inşa edilmiş olup, Windows, Linux veya tek bir makinede başlı veya başsız çalışabilen esnek dağıtım seçenekleri sunar.

🌟 **AfiLite (aktif olarak geliştirilmektedir)**

## 🇬🇧 Dual-Mode Architecture: Headful & Headless

AfiLite is designed to adapt to various use cases:

-   **Headful Solution:** With a ready-to-use user interface, you can set up and use the system directly without any technical knowledge.
-   **Headless Solution:** Thanks to its API-driven architecture, you can integrate AfiLite with your custom designs or existing software infrastructure.

This offers a flexible structure catering to both technical teams and those without technical expertise.

## 🇹🇷 Çift Modlu Yapı: Başlı ve Başsız

AfiLite, farklı kullanım senaryolarına uyum sağlayacak şekilde tasarlandı:

-   **Başlı Çözüm:** Hazır kullanıcı arayüzü sayesinde hiçbir teknik bilgiye gerek kalmadan sistemi doğrudan kurup kullanabilirsiniz.
-   **Başsız (Headless) Çözüm:** API tabanlı mimari sayesinde kendi özel tasarımlarınızı veya mevcut yazılım altyapınızı AfiLite ile entegre edebilirsiniz.

Bu sayede hem teknik ekiplere hem de teknik bilgiye sahip olmayanlara hitap eden esnek bir yapı sunuyoruz.

## 🇬🇧 Security First

Where money and trust are involved, security is paramount. AfiLite ensures a reliable system with:

-   JWT-based authentication for secure session management.
-   Role-based access control (RBAC) clearly separating admin, brand, influencer, and customer roles.
-   SQLite database offering simple, fast, and reliable usage.
-   Transparent logging and tracking of data: Every operation is traceable within the system.

This approach builds trust among brands, influencers, and customers.

## 🇹🇷 Güvenlik Önceliğimiz

İşin merkezinde para ve güven varsa, güvenlik kritik önem taşır.
AfiLite şu önlemlerle güvenilir bir sistem sağlar:

-   JWT tabanlı kimlik doğrulama ile güvenli oturum yönetimi.
-   Role-based access control sayesinde admin, marka, influencer ve müşteri rollerinin net ayrımı.
-   SQLite veritabanı basit, hızlı ve güvenilir kullanım imkânı sunar.
-   Veriler üzerinde şeffaf kayıt ve takip: Her işlem sistemde izlenebilir.

Bu yaklaşım, hem markaların hem influencerların hem de müşterilerin güvenini artırır.

## 🇬🇧 Architecture & Technology

AfiLite is built with modern, lightweight, yet powerful technologies:

-   Node.js & Express.js → Fast, scalable, and developer-friendly backend.
-   SQLite → Easy setup, low resource usage, and high performance.
-   RESTful API → Easy integration with external systems.
-   Modular structure → Allows developers to customize desired parts.

This technology stack is ideal for both small projects and large brands.

## 🇹🇷 Mimari ve Teknoloji

AfiLite modern, hafif ama güçlü teknolojilerle inşa edildi:

-   Node.js & Express.js → Hızlı, ölçeklenebilir ve geliştirici dostu backend.
-   SQLite → Kolay kurulum, düşük kaynak kullanımı ve yüksek performans.
-   RESTful API → Dış sistemlerle kolay entegrasyon.
-   Modüler yapı → Geliştiricilerin istediği parçaları özelleştirmesine imkân verir.

Bu teknoloji yığını, hem küçük projeler hem de büyük markalar için idealdir.
